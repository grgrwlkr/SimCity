# Цель визуального апгрейда (постановка для /goal)

Текст ниже — ровно то, что установлено как цель сессии 2026-09-09. Результаты по фазам
пишутся в `docs/plans/2026-09-09-visual-baseline.md`.

```
Цель: стилизованный реализм — плотный правдоподобный город в духе top-down GTA IV.
НЕ фотореализм: процедурная генерация и один текстурный атлас, без PBR-паков и GI.
База: Bevy 0.19, орто-Camera3d, vertex-colored меши на одном белом StandardMaterial, текстур в
assets/ нет. Контекст: docs/plans/2026-07-12-pseudo3d-migration-roadmap.md.

## Фаза 0 — baseline (первой, до правок)
Замерить на test city: FPS, ms/кадр днём при полном солнце и ночью, draw calls, число сущностей.
Tracy (--release --features profile_tracy), скриншот через MCP, записать в docs/plans/.
Фазы сравниваются с ним, а не с числами роадмапа (2026-07-12).

## Фаза 1 — свет и пост
ACES-тонмаппинг вместо Tonemapping::None (палитру перебрать под него), SSAO, bloom, мягкие тени,
цветокор, виньетка, низкое солнце. Числа — в новый assets/config/render.ron + parse-тест;
живые ручки — в UiSettings рядом с zoom_ease.
Приёмка: скриншот до/после в одинаковых условиях; FPS ≥ baseline −10%.

## Фаза 2 — перспектива на ближнем зуме
Projection::Perspective вблизи, плавный переход в Orthographic на дальнем; порог и жёсткость —
в render.ron. Критично: пикинг (cursor_tile()), чанк-куллинг по 4 лучам и область миникарты
работают в обоих режимах — это call-sites, где viewport_to_world_2d молча возвращал мусор.
Приёмка: тест «клик попадает в тот же тайл в обеих проекциях», миникарта не врёт,
DebugDumpCamera отражает режим.

## Фаза 3 — текстурный атлас
Один атлас: асфальт с трещинами, плитка тротуара, бордюры, фасады, гравий на крышах, изношенная
зебра. Требование: ОДИН материал + UV в вершинах (материал на цвет = смерть батчинга, урок фазы 7).
Текстуры процедурно или CC0 (источник и лицензия в assets/README.md). Vertex colors — тинт поверх.
Приёмка: все тинты и 5 оверлеев (Height/Water/Roads/LandValue/Pollution) работают как раньше;
draw calls не выросли; скриншот.

## Фаза 4 — пропсы
Фонари, провода, вывески (ночью emissive), навесы, баки, парковка у обочины, износ разметки.
Схема деревьев из фазы 7: спавн ОДИН раз + Visibility-toggle (despawn-чурн переиспользовал entity
ids и сдвигал сим-тайминги, см. soak) и NotShadowCaster (800 кастеров: 72→22 FPS).
Приёмка: soak-пин и determinism-фингерпринт зелёные; FPS ≥ baseline −15%.

## Фаза 5 — перф и оптимизация (закрывающая)
Tracy на БОЛЬШОМ городе. Сначала показать узкое место, потом чинить — только подтверждённое
профилировщиком: chunk-меши 16×16 (отложенная фаза 3 роадмапа) при упоре в draw calls; каскады
теней (maximum_distance, резолюция); LOD пропсов на дальнем зуме; par_iter в RenderSync.
Приёмка: ≥60 FPS на test city, не ниже baseline на большом городе, таблица «было/стало» по фазам.

## Инварианты (каждая фаза)
1. Симуляция не меняется; determinism-фингерпринт и soak-пины зелёные; рендер не читает/не пишет sim.
2. Новые Update-системы — явно в GameSet::RenderSync, FixedUpdate — в свой саб-сет (иначе ambiguity-пины).
3. Intersection Traffic Invariants (STRICT) не трогать — работа чисто визуальная.
4. tile↔world только через simcity_core::game::map::coords, никаких inline-формул.
5. Всё новое наблюдаемо через MCP/BRP под dev, debug_dump работает.
6. Числа — в RON, не в коде. Новый RON = parse-тест.

## Процесс
- TDD: тест до кода, три прогона (суита ДО правки, красный по ожидаемой причине, зелёный).
- Конец фазы: cargo fmt --all → clippy --all-targets --all-features -D warnings → test --workspace
  → коммит на main (Conventional Commits, английский).
- Картинку верифицировать только скриншотом из живой игры (--features dev). Старую копию гасить;
  скриншот раньше ~3.5 с после старта бывает чёрным (прогрев Metal).
- FPS мерить в одинаковых условиях (город, час, зум), докладывать против baseline.
- Долг фазы 7: рендер-секции docs/architecture.md и README ещё про 2D.

## Не делать
- Фотореализм: PBR-паки, нормалмапы, SSR/GI.
- Материал на цвет и любое размножение материалов.
- Попутный рефакторинг sim/экономики/трафика.
- Приёмку фазы без цифр FPS.
```

## Поправки, которые внесли замеры

Фаза 0 показала, что часть постановки опиралась на неверные предпосылки. Правки не в текст цели,
а в порядок работ — обоснования в `2026-09-09-visual-baseline.md`:

- **Chunk-меши в фазе 5 почти наверняка не понадобятся.** Draw calls не являются узким местом:
  ~22 тысячи видимых мешей схлопываются в ~80 групп, `render_system` стоит 1.3 мс. Начинать
  фазу 5 надо с каскадов теней — они забирают 7 мс из 10.6.
- **Bloom из фазы 1 выключен по умолчанию.** Он требует HDR-таргет и стоит 5.3 мс; ручка осталась,
  включать после фазы 5.
- **«FPS ≥ baseline −N%» меряется только без vsync.** Под vsync обе конфигурации упираются в 60 и
  критерий слепнет; для этого добавлена переменная `SIMCITY_PRESENT_MODE=immediate`.
