# Раскладка десяти элементов HUD

Десять: **оболочка** (стекло, зоны экрана, слои), **HUD-бар**, **палитра инструментов**,
**подсказка у клетки**, **панель карт данных**, **тосты**, **экран бюджета**, **панель
советника**, **стартовый экран**, **панель целей**. Состояния каждого — `states.md`; токены — `tokens.md`.

Числа пикселей взяты из Rust-раскладки (`space.px(n)` = `n × 4 px`) и записаны в токенах
отступов. Где я отступил от Rust — сказано отдельно.

---

## 1. Оболочка: зоны экрана и слои

Схема экрана 1280×800 — `assets/layout-map.svg` (открывается в браузере). В тексте:

```
┌──────────────────────────────────────────────────────────────┐
│ 12                    ┌───── HUD-бар ─────┐                  │ верхняя полоса 56 px
│                       └───────────────────┘                  │
│ ┌── карты данных ──┐                        ┌── тосты ──┐    │ 72 px от верха
│ │  260 px          │                        │ 320 px    │    │
│ └──────────────────┘        ИГРОВОЕ         └───────────┘    │
│                              ПОЛЕ                            │
│ ┌── советник ──────┐      (кликается)                        │ 352 px от верха
│ │  420 px          │                                         │
│ └──────────────────┘                                         │
│                     ┌──── палитра инструментов ────┐         │
│ 12                  └──────────────────────────────┘      12 │ нижняя полоса 96 px
└──────────────────────────────────────────────────────────────┘
                                 12
```

- Отступ от края окна — `--hud-safe-edge` 12 px (`--hud-safe-edge-wide` 16 px при `pointer: coarse`).
- Верхняя полоса 56 px и нижняя 96 px — «занято HUD». Камера может ставить туда карту, но
  ничего кликаемого на карте туда не помещается.
- Левая колонка — панели чтения (карты данных, советник), правая — события (тосты) сверху и цели
  сценария снизу, над нижней полосой (§10). Центр свободен: там стоит подсказка у клетки и там строят.
- Слои: панели 10, тосты 20, подсказка 30, скрим 35, бюджет 40, меню 50.
- Корень каждой панели — только раскладка, `pointer-events: none`; кликает сама панель
  (`states.md`, «Правило клика сквозь HUD»).
- Все панели — `.hud-glass` из `tokens.md`.

## 2. HUD-бар

Сверху по центру, `top: 12px`. Одна строка, слева направо:

```
┌──────────────────────────────────────────────────────────────────────┐
│  $37 994   День 3, 09:00   Население 120  │ ⏸ ×1 ×3 ×10 ×60 ×360 │ ×1,0 │ Бюджет  Советник │
└──────────────────────────────────────────────────────────────────────┘
   17px/650     14px            14px            кнопки 14px        12px     14px
```

- padding `16px` по горизонтали, `8px` по вертикали; `column-gap: 20px`; радиус `--hud-radius-panel`;
  тень `--hud-shadow-bar`.
- Деньги: `--hud-size-title`, вес 650, `tabular-nums`, разряды неразрывным пробелом. Минус —
  `--hud-negative` (порт `hud_bar.rs:185-189`).
- Часы и население: `--hud-size-body`, `tabular-nums`. Часы — «День N, ЧЧ:ММ»; секунды из
  `Hud.tsx:128` убрать: они меняются 10 раз в секунду и превращают бар в счётчик.
- Скорости: шесть кнопок из TS (`Paused / X1 / X3 / X10 / X60 / X360`, `Hud.tsx:13-21`), а не
  четыре как в Rust. Ширина кнопки — не меньше `--hud-target-min`, зазор `--hud-space-2`,
  выбранная — `--hud-accent-fill` + кромка.
- Реальная скорость `×1,0` — `--hud-size-caption`, `--hud-ink-muted`, показывается всегда:
  это единственный признак, что игра не успевает (`realRate`).
- Справа — «Бюджет» и «Советник»: переключатели панелей, `aria-pressed` по открытости
  (порт `spawn_budget_toggle`, `budget_panel.rs:132-155`).
- **Без `?debug=1` в баре нет ни тика, ни FPS, ни двух строк статистики трафика и служб**
  (`Hud.tsx:130-136, 161-162`) — это порт `dev_ui_gated_*`, критерий этапа 6c.

## 3. Палитра инструментов

Снизу по центру, `bottom: 12px`. Пять групп через вертикальный разделитель 1 px
`--hud-glass-border`; внутри группы кнопки через `--hud-space-4`, между группами `--hud-space-12`.

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│ ┌───┐┌───┐┌───┐┌───┐ │ ┌───┐┌───┐┌───┐ ┌──┐┌──┐┌──┐ │ ┌───┐…┌───┐ │ ┌──┐┌──┐┌──┐ │ ┌──┐┌──┐ │
│ │ ▤ ││ ▤ ││ ▤ ││ ⇄ │ │ │ ⌂ ││ ▣ ││ ⚙ │ │низ││ср││выс│ │ │ 🜂 │…│ ⛹ │ │ │ ⚡││ 💧││ 🗑│ │ │ ⌫ ││ ? │ │
│ │2 п││4 п││6 п││одн│ │ │Жил││Ком││Пром│ └──┘└──┘└──┘ │ └───┘ └───┘ │ └──┘└──┘└──┘ │ └──┘└──┘ │
│ │ 1 ││ 1 ││ 1 ││ O │ │ │ 2 ││ 3 ││ 4 │              │             │              │          │
│ └───┘└───┘└───┘└───┘ │ └───┘└───┘└───┘              │             │              │          │
│      дороги          │        зоны и плотность      │   службы    │   ресурсы    │  правка  │
└─────────────────────────────────────────────────────────────────────────────────┘
```

Кнопка инструмента — колонка из трёх:

```
┌──────────────┐  min-width 56, padding 8/4, radius --hud-radius-control
│    [24×24]   │  иконка, currentColor
│   2 полосы   │  14px --hud-ink
│      1       │  12px --hud-ink-muted, чип --hud-radius-pill, фон --hud-glass-highlight
└──────────────┘
```

Состав групп — порт `GROUPS` (`tool_palette.rs:49-124`): дороги (2/4/6 полос + односторонняя),
зоны (жилая, коммерческая, промышленная + плотность низкая/средняя/высокая), службы (пожарная,
полиция, больница, школа, университет, парк, светофор), ресурсы (электростанция, водокачка,
свалка), правка (снос, осмотр). Иконки и их метрика — `icons.md`.

Отличия от Rust, намеренные:

- Подпись не заменяет иконку, а стоит под ней: 22 кнопки подряд одними словами не читаются на
  скорости, а одними иконками — не опознаются новичком.
- Кнопка, закрытая вехой, остаётся в палитре и **не исчезает**: она показывает, что в игре
  будет школа. Иконка и подпись — `--hud-ink-disabled`, вместо чипа хоткея — caption
  «Откроется при 250 жителях» (текст из `rust-final:crates/simcity_sim/src/game/milestones.rs:43-49`), `aria-disabled="true"`,
  `title` с той же строкой.
- Плотность — не инструмент, а модификатор зон: три кнопки стоят в группе зон и подсвечиваются
  независимо от выбранного инструмента (порт `DensityButton`, `tool_palette.rs:22`).
- Односторонняя дорога — переключатель в группе дорог, `aria-pressed`.

## 4. Подсказка у клетки

Идёт за курсором: `left: x + 16`, `top: y + 16` (порт `place_tile_tooltip`,
`tile_tooltip.rs:210`). Переворачивается к другой стороне курсора, когда не помещается
до края окна: это в Rust-версии отсутствовало и там подсказка уезжала за экран.

```
┌────────────────────────────────────────┐  --hud-glass-strong, radius --hud-radius-control
│ Дорога 2 полосы, $120                  │  14px --hud-ink          padding 12/6
│ Покрывает 8 клеток вокруг              │  12px --hud-ink-muted    row-gap 2
└────────────────────────────────────────┘  max-width 320, --hud-shadow-tooltip
```

- Первая строка — эффект и цена: «эффект, $N» или «эффект, бесплатно» (`tooltip_lines`,
  `tile_tooltip.rs:29-46`).
- Вторая строка — либо радиус охвата (`--hud-ink-muted`), либо **причина отказа**
  (`--hud-negative`). Красный текст — причина, по которой подсказка берёт плотное стекло
  (`contrast.md`).
- Нет второй строки → блок скрывается (`display: none`), панель не оставляет пустой полосы.
- Подсказки нет: над HUD, в режиме «Осмотр», когда сказать нечего.
- Вся подсказка `pointer-events: none`.

## 5. Панель карт данных

Слева, `top: 72px`, `left: 12px`, ширина 260 px вместе с padding и кромкой (`box-sizing: border-box`),
padding 8, `row-gap: 8`.

Заголовок — кнопка «Карты данных» с `aria-expanded`: она сворачивает и разворачивает панель. По
умолчанию панель свёрнута до заголовка; когда слой выбран, справа в заголовке стоит его имя
(12px `--hud-ink`). Свёрнутая панель — одна строка высотой меньше 280 px, так что советник на
`top: 352px` свободен; выбранная карта при этом остаётся на экране. Развёрнутая панель — схема ниже.
Панель и советник делят левую колонку по очереди (§8, `states.md`, «Левая колонка»).

```
┌── 260 px ──────────────────┐
│ Карты данных   Стоимость з.│  заголовок-кнопка, 12px; справа имя слоя
│ ┌────┐┌──────────┐┌──────┐ │  кнопки слоёв, перенос по строкам,
│ │Нет ││Стоимость ││Грязь │ │  12px, padding 8/4, gap 4
│ └────┘└──────────┘└──────┘ │  выбранная — --hud-accent-fill + кромка
│ … 17 кнопок …              │
│ ┌────────────────────────┐ │  легенда: градиент 10 px высотой,
│ │▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ │  9 стопов, радиус 4
│ └────────────────────────┘ │
│ Низкая            Высокая  │  12px --hud-ink-muted, по краям
│ ────────────────────────── │
│ Стоимость земли: 68 %      │  14px --hud-ink, значение под курсором
└────────────────────────────┘
```

Легенда бывает двух видов — градиент и образцы; состав, цвета и правила — `data-map-legend.md`.
Пока карта данных открыта, свет полуденный и виньетка выключена (критерий U4) — панель об этом
не сообщает, это делает рендер.

## 6. Тосты

Справа, `top: 72px`, `right: 12px`, колонка вниз, `row-gap: 4`, максимум 4 строки
(`MAX_TOASTS`, `toasts.rs:17`).

```
   ┌─┬───────────────────────────────────┐
   │▌│ 🔥 Пожар на Вязовой улице     ×3  │  кромка слева 3 px в цвете вида,
   └─┴───────────────────────────────────┘  --hud-glass-strong, radius 8,
   ┌─┬───────────────────────────────────┐  padding 12/6, 14px --hud-ink,
   │▌│ ✦ Открыта школа                   │  счётчик — чип --hud-radius-pill
   └─┴───────────────────────────────────┘
```

- Цвет кромки: `Info` → `--hud-accent`, `Warning` → `--hud-warning`, `Error` → `--hud-negative`,
  `Achievement` → `--hud-positive` (порт `toasts.rs:81-86`).
- Цвет не единственный носитель вида: слева от текста иконка вида (`icons.md`, «состояния»).
- Повторы — не новая строка, а `×N` в чипе справа (`toast_label`, `toasts.rs:30-36`).
- Клик по строке ведёт камеру к месту события (`on_toast`, `toasts.rs:121-139`); строка с местом
  получает `cursor: pointer` и `--hud-accent-ink` у текста, строка без места — не кликается
  и курсор не меняет.
- Появление — сдвиг справа 8 px за `--hud-motion-panel`; при `prefers-reduced-motion` без сдвига.
- Ширина по содержимому, не больше 320 px; текст в одну строку с обрезкой.

## 7. Экран бюджета

Модальный: скрим `--hud-scrim` на весь экран, панель по центру по горизонтали, `top: 72px`,
ширина 560 px, padding 16, `row-gap: 12`, тень `--hud-shadow-panel`, `z-index: --hud-z-modal`.
Колонки: 180 / 120 / 120, зазор 8 (порт `BudgetUi::cell`, `budget_panel.rs:284-300`).

```
┌── 560 px ────────────────────────────────────────────────┐

```

- Кнопки `−` и `+` — нейтральная заливка `--hud-glass-highlight`, ширина и высота

  не прыгает при смене с 9 % на 10 %.

- Строки, где суммы нет, показывают `—` в `--hud-ink-muted`: пустая ячейка читается как ошибка.
- Отказанный заём ничего не меняет и объясняется строкой под кнопками (`--hud-warning`),
  а не исчезновением кнопки (порт `budget_panel.rs:196-199`).
- Порядок строк — `ITEMS` (`budget_panel.rs:59-69`): доходы, потом расходы, потом «Итого».

## 8. Панель советника

Слева под панелью карт данных: `top: 352px`, `left: 12px`, ширина 420 px, padding 16,
`row-gap: 8`. Не модальная: город продолжает жить, игрок может строить с открытым советником.

```
┌── 420 px ──────────────────────────────────┐
│ Советник                              12px │ --hud-ink-muted
│ Пробки душат центр                    17px │ --hud-ink, вес 650 — худшая проблема
│ Не хватает школ                       14px │ --hud-ink-muted
│ Растёт преступность на востоке        14px │ --hud-ink-muted
│ ────────────────────────────────────────── │
│ Последние события                     12px │ --hud-ink-muted
│ День 12: Пожар на Вязовой улице ×3    14px │ --hud-ink
│ … до пяти строк …                          │
└────────────────────────────────────────────┘
```

- Здоровый город: одна строка «Ничего не требует внимания», 17 px `--hud-ink` (порт
  `advisor_panel.rs:181-188`).
- Худшая проблема крупнее двух следующих — это и есть вся иерархия панели, других приёмов
  выделения не нужно.
- Блок «Последние события» появляется, только если история не пуста (`advisor_panel.rs:211-219`);
  строки — «День N: текст ×K», пять последних.
- Левая колонка на любой ширине занята одной панелью: открытие советника сворачивает карты данных,
  разворот карт данных закрывает советника (`states.md`, «Левая колонка»). Свёрнутые карты данных
  (заголовок с именем слоя) стоят над советником и его не перекрывают.

## 9. Стартовый экран

Карточка по центру экрана, ширина 420 px, padding 24, `row-gap: 12`, `z-index: --hud-z-menu`.
За ней — карта (в меню это пустая карта), без скрима: город виден и продаёт себя сам.

```
            ┌── 420 px ──────────────────────────────┐
            │ SimCity                           24px │ --hud-ink, вес 650
            │ Проложите улицы. Город построит себя.  │ 14px --hud-ink-muted
            │                                        │
            │ ┌────────────────────────────────────┐ │
            │ │ Новая карта                   20px │ │ заливка --hud-glass-highlight,
            │ │ Пустая песочница на новой карте    │ │ padding 16/10, radius 8
            │ └────────────────────────────────────┘ │
            │ ┌────────────────────────────────────┐ │
            │ │ Демо-город                    20px │ │
            │ │ Готовый город: посмотреть, поменять│ │
            │ └────────────────────────────────────┘ │
            │ Сценарии                          12px │ --hud-ink-muted
            │ ┌────────────────────────────────────┐ │
            │ │ Живой город                   20px │ │
            │ │ Цели: население 5 000              │ │ 12px --hud-ink-muted
            │ └────────────────────────────────────┘ │
            │ … по кнопке на сценарий из SCENARIOS … │
            └────────────────────────────────────────┘
```

- Пункты — две строки: название 20 px и строка целей 12 px (`goals_line`,
  `start_screen.rs:169-190`): «Цели: население 50, счастье 60 %», казна — как деньги в баре.
  Сценарий без целей, в том числе любой вне каталога пресетов, — «Свободная игра».
- Подписи не называют сид и тестовый город: «Новая карта» — «Пустая песочница на новой карте»,
  «Демо-город» — «Готовый город: посмотреть и поменять» (`LoadTestCity`). «Живой город» занят
  названием сценария.
- Заливка пункта — нейтральная `--hud-glass-highlight`, **не акцентная**: акцент занят выбранным,
  а здесь ничего ещё не выбрано (комментарий `start_screen.rs:148` — то же решение).
- Наведение и фокус — по базовой таблице. `Enter` в меню по-прежнему делает `setState('InGame')`
  на текущем мире (`Hud.tsx`, `useStateHotkeys`).
- В меню нет ни одного dev-элемента: ни сида, ни FPS, ни кнопки «тестовый город»
  (порт `dev_ui_gated_game_interface_shows_no_developer_element`, `hud_bar.rs:304`).
- Список сценариев берётся из `SCENARIOS` (`packages/bridge/src/scenarios.ts`) в его порядке, цели —
  из `SCENARIO_PRESETS` (`menuScenarios()` в `StartScreen.tsx`).
- Каждый пункт — `<button>`, выбор уходит в пропсы: `onStart({ name })` для сценария,
  `onStart({ name: 'sandbox', seed })` для новой карты (64 случайных бита, новые на каждое нажатие),
  `onDemoCity()` для демо-города. Приложение открывает выбранное на свежей странице, как раньше
  ссылка: так ничего от текущего мира не переносится.
- Корень `.hud-menu` — только раскладка (`pointer-events: none`), клики берёт карточка. Карточка
  не выше окна минус два отступа края и прокручивается внутри; на узком окне её ширина —
  `100vw` минус два отступа.
- Test id: `hud-menu`, `menu-new-map`, `menu-demo-city`, `menu-scenario-<name>`.

## 10. Панель целей

Цели сценария из каталога, который идёт сейчас (`snapshot.scenario`, P3). Правая колонка, снизу:
`right: 12`, `bottom: 108` (нижняя полоса 96 плюс отступ края), ширина 320 px, как у тостов, слой
панелей 10.

```
                                           ┌── 320 px ─────────────────────┐
                                           │ Первый город           1 из 2 │ 14px/650 · 12px --hud-ink-muted
                                           │ ✓ Население 1 234 из 50       │ 14px --hud-ink, ✓ --hud-positive
                                           │ Счастье 55 % из 60 %          │ 14px --hud-ink-muted
                                           │ Сценарий пройден              │ 14px/650 --hud-positive
                                           └───────────────────────────────┘
```

- Место: не в баре — бар уже полон на 1280 px, а цели читают не каждую секунду. Не прямо под
  тостами — их столбец растёт вниз, и панель прыгала бы с каждым тостом. Нижний край правой
  колонки свободен: палитра стоит по центру нижней полосы, советник и карты данных слева.
  Длинный столбец тостов может лечь поверх панели: слой тостов 20 выше, тост важнее и уходит сам.
- Строка — «<мера> <сейчас> из <цель>» в единице цели: жители с разрядами, казна как в баре,
  счастье в процентах. Выполненная — с ✓ и в `--hud-ink`, невыполненная — в `--hud-ink-muted`.
  Выполненная цель не фиксируется (Rust `update_scenario_progress`): упало население — ✓ ушла.
- «Сценарий пройден» — только когда выполнены все цели; у пресета без целей его не бывает.
- Панели нет вовсе, когда показывать нечего: обычная игра, сценарий вне каталога, пресет без
  целей (песочница, новая карта).
- Нажимать нечего: вся панель `pointer-events: none`, карта под ней кликается.
- Test id: `objectives`; строка несёт `data-met`.
