# Иконки инструментов и состояний

Файл: `docs/design/hud/assets/tools.svg` — один спрайт, 29 символов. Смотреть вживую:
`docs/design/hud/assets/preview.html` (по http, см. «Как подключать»).

## Метрика

| Параметр | Значение |
|---|---|
| viewBox | `0 0 24 24` |
| живая область | 20×20, поля по 2 px со всех сторон |
| обводка | `stroke-width: 2`, у второстепенных деталей `1.5` (класс `.thin`) |
| концы и стыки | `round` / `round` |
| заливка | `none`; сплошная деталь — класс `.solid` (`fill: currentColor; stroke: none`) |
| цвет | только `currentColor` — иконка красится тем же токеном, что и текст рядом |
| размер на экране | 24×24 CSS-px в палитре и в тостах, 20×20 в шапках панелей |
| сетка | линии по целым и половинным координатам; диагонали свободны |
| оптический центр | тяжёлая часть ниже геометрического центра (здания и деревья стоят на земле) |

Правило: **иконка не несёт смысла одна**. В палитре под ней всегда подпись, в тосте — текст
события. Иконка ускоряет узнавание, а не заменяет слово.

## Формат и как подключать

- Формат — **SVG-спрайт**: один файл, `<symbol>` с `id`, страница берёт символ через `<use>`.
  Растр не нужен: интерфейс векторный, масштабируется под любой DPR без вариантов ×2 и ×3.
- Разработчик копирует `tools.svg` в `packages/app/public/icons/tools.svg` — оттуда Vite отдаёт
  его как статический файл, а в Electron он попадает в `out/renderer` и доступен по
  `app://bundle/icons/tools.svg`.
- Разметка:
  ```html
  <svg class="hud-icon" aria-hidden="true"><use href="/icons/tools.svg#tool-road-2" /></svg>
  ```
  `aria-hidden`, потому что рядом всегда есть текст; если иконка оказалась одна (кнопка без
  подписи), у кнопки обязателен `aria-label`.
- **Cross-file `<use>` не работает по `file://`** — Chromium считает каждый файловый URL
  отдельным origin и молча не рисует символ. Проверено: по `file://` на каждый `<use>` идёт
  `Unsafe attempt to load URL … 'file:' URLs are treated as unique security origins`; после
  подъёма http-сервера — 0 ошибок консоли. Превью и e2e открывают страницу по http; в игре это и так так.
- Альтернатива, если спрайт мешает: тот же исходник разрезается на файлы по иконке и
  инлайнится сборщиком. Формат символов от этого не меняется.

`panel-datamap` — три слоя карты.

### Виды событий в ленте (4)

`state-info` — круг с «i»; `state-warning` — треугольник с «!»; `state-error` — круг с крестом;
`state-achievement` — звезда. Они стоят слева от текста тоста и несут вид события **вместе** с
цветом кромки, чтобы вид читался без цвета (`contrast.md`, «Образцы легенды»).

## Что проверено и что осталось

Проверено в headless Chromium (`.scratch/shot.ts`, страница по http): все 29 символов
отрисованы, у каждого `getBBox()` не меньше 8×8 px, 0 ошибок консоли. Первая версия
`tool-density-low` дала bbox высотой 4 px — перерисована.

Открытый вопрос к разработчику: `tool-bulldoze` на 24 px читается слабее прочих. Если на живом
HUD он не опознаётся, замена — перечёркнутый контур здания; скажите `Q:`, и я переделаю символ.
