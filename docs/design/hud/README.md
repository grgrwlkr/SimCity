# Визуальный язык HUD — этап 6c

**Направление в одну фразу:** градостроитель смотрит на город, а не на интерфейс — HUD это
дымчатое стекло по краям кадра, которое даёт одну цифру, один инструмент и один ответ «что
будет, если кликнуть», и уходит с дороги.

Из этой фразы следует всё остальное: тёмное полупрозрачное стекло (город виден сквозь панель),
один акцентный цвет только для выбранного, центр экрана всегда свободен, ни одна панель не
модальна кроме бюджета.

## Что читать и в каком порядке

| Файл | Что внутри | Кому |
|---|---|---|
| `tokens.md` + `assets/tokens.css` | все значения: цвет, типографика, отступы, радиусы, тени, слои, движение | U1 первым делом |
| `contrast.md` + `assets/contrast-check.ts` | числа контраста над светлой и тёмной картой, ворота для юнит-теста | U1 |
| `states.md` | состояния любого элемента: обычное, наведение, нажатие, фокус, выбрано, выключено, закрыто вехой; пусто / загрузка / ошибка; длинный текст; клавиатура | U1–U8 |
| `layout.md` + `assets/layout-map.svg` | раскладка всех девяти элементов с пикселями | U1–U8 |
| `icons.md` + `assets/tools.svg` | 29 иконок: что нарисовано, метрика, формат, подключение | U2 |
| `data-map-legend.md` | легенда 17 слоёв: градиенты, образцы, значение под курсором | U4 |

Девять элементов HUD: **оболочка** (стекло, зоны, слои) · **HUD-бар** · **палитра инструментов**
· **подсказка у клетки** · **панель карт данных** · **тосты** · **экран бюджета** ·
**панель советника** · **стартовый экран**.

## Превью

```bash
cd docs/design/hud/assets && python3 -m http.server 8765
# открыть http://localhost:8765/preview.html
```

По `file://` иконки не нарисуются — Chromium блокирует cross-file `<use>` (`icons.md`).

## Решения, которые стоит знать до чтения

1. **Тема одна.** HUD не следует `prefers-color-scheme`: его фон — город, а не страница. Светлый
   и тёмный случай — это полдень и ночь на карте, и оба закрыты числами в `contrast.md`.
2. **Токены взяты из Rust, где они были.** `theme.rs` пережил три теста на контраст и
   прозрачность; переписывать палитру с нуля было бы потерей проверенного. Добавлены три
   токена, которых Rust не имел, и каждый объяснён.
3. **Контраст считается в sRGB, а не в линейном свете.** Rust смешивал стекло с миром линейно;
   браузер так не делает. Разница до двух раз. Подробно — `contrast.md`, «Метод».
4. **Цвет никогда не единственный носитель смысла.** Ни в легенде, ни в тостах, ни в подсказке:
   рядом всегда слово, число или иконка формы.
5. **Размытия стекла нет.** Причина — в `tokens.md`; ручка оставлена, но включается только
   после замера кадра.
