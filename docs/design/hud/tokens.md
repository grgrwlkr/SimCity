# Токены HUD — значения

Готовый файл: `docs/design/hud/assets/tokens.css`. Копируется в `packages/app/src/hud-tokens.css`
и импортируется перед `styles.css`. Ни одно значение цвета, размера или отступа в `packages/ui`
не пишется мимо переменной: значение, которого нет здесь, — дефект.

Проверка чисел контраста и метод — `contrast.md`. Состояния — `states.md`. Раскладки — `layout.md`.

## Одно решение, из которого следует остальное

**HUD не имеет светлой и тёмной темы.** Его фон — не страница, а трёхмерный город, который сам
меняет яркость от ночи к полудню. Поэтому скин один: тёмное дымчатое стекло, светлый текст,
и требование к контрасту формулируется не «в тёмной теме», а «над самым светлым и самым тёмным
кадром карты». Блок `@media (prefers-color-scheme: dark)` в `packages/app/src/styles.css:11`
остаётся и отвечает только за оболочку страницы до появления canvas (сообщение «Запуск
симуляции…», фон `body`). На HUD он не распространяется.

| Переменная | Значение | Роль |
|---|---|---|
| `--hud-ink` | `#f2f5fa` | основной текст на стекле |
| `--hud-ink-muted` | `#b3bac7` | подписи, единицы, подсказки, вторые строки |
| `--hud-ink-disabled` | `#9aa1ac` | текст выключенного контрола |
| `--hud-glass` | `rgb(15 20 28 / 0.80)` | заливка бара, палитры, панелей |
| `--hud-glass-strong` | `rgb(15 20 28 / 0.92)` | подсказка у клетки и тост: там живёт красный текст |
| `--hud-glass-solid` | `#0f141c` | подложка образца легенды, жёлоб скролла |
| `--hud-glass-highlight` | `rgb(255 255 255 / 0.10)` | блик по верхней кромке; он же нейтральная заливка кнопки |
| `--hud-glass-border` | `rgb(255 255 255 / 0.12)` | контур панели, разделитель групп |
| `--hud-scrim` | `rgb(6 8 11 / 0.55)` | затемнение под экраном бюджета |
| `--hud-accent` | `#5c9eff` | кромка выбранного, кольцо фокуса, заливки — **не текст** |
| `--hud-accent-ink` | `#a8ceff` | акцент, когда его надо прочитать буквами |

| `--hud-accent-fill-strong` | `rgb(92 158 255 / 0.45)` | он же под нажатием |
| `--hud-positive` | `#73d98c` | деньги вверх, размещение разрешено, достижение |
| `--hud-negative` | `#ff736b` | деньги вниз, отказ, ошибка |
| `--hud-warning` | `#ffc74d` | скоро потребует внимания |
| `--hud-hover` | `rgb(255 255 255 / 0.08)` | наведение |
| `--hud-press` | `rgb(255 255 255 / 0.16)` | нажатие |

Значения `ink`, `ink-muted`, `glass`, `glass-highlight`, `glass-border`, `accent`, `positive`,
`negative`, `warning` — те же, что в `rust-final:crates/simcity_frontend/src/game/hud/theme.rs:74-82`,
переведённые из `Color::srgb(…)` в hex. Три токена добавлены, потому что Rust-версия ими не
пользовалась, а в вебе они нужны: `--hud-ink-disabled`, `--hud-accent-ink` (см. `contrast.md`,
«Акцент не бывает текстом») и `--hud-glass-strong`.

### Почему `--hud-press` — белый, а не чёрный

Bevy-версия нажатия не рисовала вовсе. Чёрная заливка над стеклом не работает: `rgb(0 0 0 / 0.14)`
над стеклом поверх ночной улицы даёт отношение к самому стеклу 1,02 — глаз не видит ничего.
Белая при 16 % даёт 1,60 к стеклу и 1,31 к наведению на всех пяти замеренных фонах (`contrast.md`,
таблица «Заливки состояний»). Поэтому шаг «обычное → наведение → нажатие» — 0 / 8 / 16 % белого
плюс `transform: translateY(1px)`.

## Типографика

Одно семейство — системное (`--hud-font`), то же, что уже стоит в `styles.css:8`. Второго
семейства нет намеренно: веб-шрифт в Electron — это загрузка и FOUT ради эффекта, которого на
дымчатом стекле не видно. Размеры — шкала 1,2 от базовых 14 px, округлённая до целых.

| Переменная | Значение | Где |
|---|---|---|
| `--hud-size-caption` | 12 px | чип хоткея, единицы, концы шкалы легенды, шапки колонок бюджета |
| `--hud-size-body` | 14 px | все показания и подписи кнопок |
| `--hud-size-title` | 17 px | деньги в баре, заголовки панелей, худшая проблема советника |
| `--hud-size-display` | 20 px | пункты стартового меню |
| `--hud-size-hero` | 24 px | название игры |

`--hud-leading-tight: 1.25` для хрома, `--hud-leading-text: 1.45` для прозы советника и бюджета.
Начертания: 450 обычное, 650 для денег, заголовков и названий пунктов меню.

**Все тикающие числа — `font-variant-numeric: tabular-nums`** (`--hud-numeric`): деньги, часы,
население, проценты ставок, FPS. Без этого бар дёргается на каждом кадре, потому что пропорциональные
цифры меняют ширину.

Размер `title` — 17 px, а не 18 px как в Rust (`theme.rs:92`): 18 выпадает из шкалы 1,2. Расхождение
намеренное, тестами Rust не закреплено.

## Отступы

База 4 px (`Spacing { unit: 4.0 }`, `theme.rs:84`). Токены названы по числу пикселей:
`--hud-space-2 / -4 / -6 / -8 / -12 / -16 / -24 / -32 / -48`. Шаг 6 px существует ради вертикали
подсказки у клетки (`space.px(1.5)` в Rust), 2 px — ради зазора между кнопками скорости.

## Радиусы и тени

`--hud-radius-swatch: 3px`, `--hud-radius-control: 8px`, `--hud-radius-panel: 12px`,
`--hud-radius-pill: 999px` (чип хоткея, счётчик повторов тоста).

| Переменная | Значение | Где | Источник |
|---|---|---|---|
| `--hud-shadow-bar` | `0 4px 16px rgb(0 0 0 / 0.35)` | бар, палитра, панель карт данных | `hud_bar.rs:89-95` |
| `--hud-shadow-panel` | `0 8px 32px rgb(0 0 0 / 0.45)` | бюджет, советник, стартовая карточка | `budget_panel.rs:111-117` |
| `--hud-shadow-tooltip` | `0 6px 20px rgb(0 0 0 / 0.45)` | подсказка у клетки, тост | новое |

## Стекло без размытия

Стекло — заливка + блик + контур, **без `backdrop-filter`**:

```css
.hud-glass {
  background-color: var(--hud-glass);
  background-image: var(--hud-glass-sheen);
  border: 1px solid var(--hud-glass-border);
  border-radius: var(--hud-radius-panel);
  box-shadow: var(--hud-shadow-bar);
}
```

Блик повторяет фрагментный шейдер `glass.wgsl:48-50` (строки 48–50): белый 10 %, затухающий к 35 % высоты.
Контур — `border` вместо кольца в шейдере (`glass.wgsl:53-55` (строки 53–55)), результат тот же.

Размытия нет по двум причинам. Первая — цитата из `glass.rs:3-6`: кадр не копируется, значит
блюра не бывает, и панель читается как стекло за счёт прозрачности, а не за счёт размытия.
Вторая — производительность: `backdrop-filter` над canvas WebGPU заставляет композитор читать
кадр обратно каждый кадр. **Второе я не замерял** — цифры нет, это причина осторожности, а не
доказанный факт. Ручка оставлена (`--hud-glass-blur: 0px`); если её поднимать, то после замера
`bun run bench` и кадрового времени в `desktop:e2e`, и число кладётся сюда.

## Слои

`--hud-z-panel: 10` → `--hud-z-toast: 20` → `--hud-z-tooltip: 30` → `--hud-z-scrim: 35` →
`--hud-z-modal: 40` → `--hud-z-menu: 50`. Canvas карты — `z-index: 0` (`styles.css:29-36`).
Подсказка у клетки выше тостов: она идёт за курсором и не должна нырять под ленту в правом
верхнем углу. Экран бюджета — единственный модальный: он один поднимает скрим.

## Движение

`--hud-motion-fast: 90ms` на наведение, нажатие и фокус — внутри бюджета обратной связи 100 мс.
`--hud-motion-panel: 160ms` на открытие панели. Смена выбранного инструмента и слоя — **без
перехода**: выбор обязан быть мгновенным. При `prefers-reduced-motion: reduce` обе длительности
становятся 0 мс (в `tokens.css` это уже сделано), тост появляется без сдвига, подсказка у клетки
не анимирует положение.

## Цели попадания и безопасная зона

`--hud-target-min: 32px` — минимальная высота кликаемого бокса для мыши; при `pointer: coarse`
медиазапрос в `tokens.css` поднимает её до `--hud-target-touch: 44px` и расширяет отступ от края.
`--hud-safe-edge: 12px` — расстояние от края окна до любой панели (в Rust `space.px(3)`).
Минимальное окно, на котором раскладка обязана держаться, — 1280×800 (размер окна Electron,
`packages/desktop/src/main.ts:70-71`).
