# Легенда карт данных

Семнадцать слоёв, две формы легенды. Цвета заданы игрой
(`rust-final:crates/simcity_sim/src/game/map/data_map.rs`) и **не меняются**: ими же красится
тайл, и их держат 11 тестов `data_map.rs`. Дизайн здесь — форма легенды, порядок кнопок и
правила читаемости, а не палитра.

## Порядок кнопок слоёв

Порядок — как в `PLAYER_OVERLAYS` (`data_map_panel.rs:37-71`), сгруппированный по смыслу.
«Путь» (`Path`) в игровую панель не попадает: это инструмент разработчика.

1. **Нет** — карта как она есть.
2. **Деньги и грязь:** Стоимость земли, Загрязнение, Пробки.
3. **Сети:** Электричество, Водопровод, Мусор.
4. **Люди:** Преступность, Пожарный риск, Здоровье, Образование, Привлекательность.
5. **Город:** Службы, Зоны, Высота, Вода, Дороги.

Кнопка — `--hud-size-caption`, padding 8/4, перенос по строкам, выбранная — `--hud-accent-fill`
плюс кромка `--hud-accent` (`states.md`).

## Форма 1 — градиент

Полоса 10 px высотой, радиус 4, **9 стопов**, выбранных равномерно от 0 до 1 той же функцией,
которой красится тайл (`GRADIENT_STOPS = 9`, `data_map.rs:145`). Под полосой — два слова
концов шкалы, `--hud-size-caption`, `--hud-ink-muted`, по левому и правому краю.

| Слой | Низкий конец | Высокий конец | Шкала |
|---|---|---|---|
| Стоимость земли | Низкая | Высокая | красный → жёлтый → зелёный |
| Загрязнение | Чисто | Грязно | зелёный → жёлтый → красный |
| Пробки | Свободно | Затор | зелёный → красный |
| Преступность | Безопасно | Криминал | зелёный → красный |
| Пожарный риск | Безопасно | Риск пожара | зелёный → красный |
| Здоровье | Плохо | Здорово | красный → зелёный |
| Образование | Нет | Образованно | красный → зелёный |
| Привлекательность | Избегают | Желанно | красный → зелёный |
| Высота | Низко | Высоко | чёрный → белый |

Правило шкалы, унаследованное из Rust и сохранённое: **красный всегда означает беду**. Где
«больше = хуже» (преступность, пожарный риск, загрязнение) шкала идёт от зелёного к красному,
где «больше = лучше» — наоборот (`data_map.rs:124-131`).

Слова концов — русские (интерфейс русский), английские оригиналы: `city_field_scale`,
`data_map.rs:134-142`.

## Форма 2 — образцы

Строка: квадрат 12×12, радиус `--hud-radius-swatch`, рядом подпись `--hud-size-body`
`--hud-ink`. Зазор 6 px, между строками 4 px.

**Каждый образец — на непрозрачной подложке `--hud-glass-solid` с кольцом
`inset 0 0 0 1px rgb(255 255 255 / 0.45)`.** Без кольца тёмно-синяя «Полиция» (`#0000e6`) даёт к
стеклу 1,89 над ночью и 1,23 над бетоном — пятно исчезает (`contrast.md`, таблица образцов).

| Слой | Образцы |
|---|---|
| Электричество | Есть электричество `#ffd91a` · Зона без питания `#e62626` |
| Водопровод | Вода `#3399ff` · Зона без воды `#e62626` |
| Мусор | Вывозится `#9e7542` · Зона без вывоза `#e62626` |
| Зоны | Жилая `#2ea638` · Коммерческая `#2e5cb8` · Промышленная `#b88f1f` |
| Дороги | Дорога `#ebebf5` |
| Вода | Вода `#2673f2` |
| Службы | Пожарная `#e60000` · Полиция `#0000e6` · Медицина `#00cc00` · Школа `#cc944d` · Университет `#8c5c9e` · Парк `#4d9e47` · Зона без покрытия `#e61a1a` |

«Службы» — семь строк: это самая длинная легенда, панель под неё рассчитана (260 px ширины,
высота растёт вниз, скролла нет).

## Значение под курсором

Под легендой — одна строка `--hud-size-body` `--hud-ink`, `tabular-nums`:

- курсор вне карты → «Наведите на клетку»;
- клетка за краем карты → «Вне карты», `--hud-ink-muted`;
- иначе — текст из `overlay_reading` (`data_map.rs:235`), например «Стоимость земли: 68 %».

Эта строка — обязательный не-цветовой канал: она одна отвечает на вопрос «что тут», когда два
синих образца рядом неразличимы.

## Слой «Нет»

Легенды нет, блок легенды и строка значения скрыты целиком (`display: none`), панель схлопывается
до заголовка и кнопок. Пустой рамки быть не должно (`states.md`, «Пустое, загрузка, ошибка»).

## Что делает рендер, а не панель

Пока открыта любая карта данных, свет ставится полуденным и виньетка выключается — иначе
градиент врёт (критерий U4 в `docs/plans/2026-09-15-web-remaining-work.md`). Панель об этом не
сообщает и ничем не отмечает: игрок видит, что карта стала ровной.
