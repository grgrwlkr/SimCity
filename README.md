# SimCity

Градостроительная игра для десктопа на TypeScript + Three.js. Целевая оболочка — Electron; Chromium используется для разработки и проверок. Мобильная версия не входит в проект. Основной режим — **региональная игра**: непрерывная карта 4 × 4 км, где игрок основывает города, строит дороги и задаёт зоны, а семьи и предприятия развивают застройку, ездят на работу и перевозят товары. **«Город у воды»** сохраняется как отдельный прототип с составными зданиями, машинами, людьми, работающим портом и анимацией строительства.

Графика этого города — ориентир для дальнейшего развития, включая транспорт, жителей, корабли и порт. Механики переносим из прежней игры по отдельности либо реализуем заново здесь. Прежняя игра имеет статус **deprecated** и сохранена в [`deprecated/`](deprecated/README.md).

## Запуск

```bash
bun install
bun run dev        # http://localhost:5174
```

Вся основная игра работает на `/` в одном приложении. Главное меню, создание региона, загрузка и управление городом переключаются без перезагрузки страницы. «Создать регион» начинает новую карту; `Enter` делает то же. «Загрузить» раскрывает список сохранённых регионов с названиями поселений и ключом карты; выбор записи продолжает именно этот мир. Повреждённые записи остаются в списке недоступными для загрузки. Кнопка «Удалить» удаляет выбранное сохранение после подтверждения; ошибка хранилища оставляет запись в списке. `Escape` закрывает список. Возврат в главное меню ставит игру на паузу, а «Продолжить» возвращает тот же мир и камеру из памяти. Небольшая ссылка «Город у воды — прототип» открывает `/city/?seed=689856`. Прежние игровые сценарии удалены из обычного запуска; первый прототип «Тихий квартал» удалён.

- `/city/?seed=<ключ>` — воспроизводимый город по ключу.
- `&view=harbor` — камера у работающего порта.
- `&view=construction` — просмотр строительства.
- `&view=houses` — одноэтажные дома с частными участками, садами и разными ограждениями.
- `&view=railway` — пассажирский вокзал, поезда и железнодорожные переезды.
- Логотип SimCity в городе возвращает в главное меню.

## Региональная игра

- `/?seed=<ключ>` открывает новую пустую карту с воспроизводимым озером, рекой от края до края, берегами и растительностью. `/?seed=<ключ>&regionId=<ID>` открывает сохранённый регион. Старые ссылки `/region/` перенаправляют на корень с сохранением параметров. Поселения и дорожную сеть создаёт игрок. Один бюджет обслуживает весь регион.
- «Регион» — отдельный режим для основания поселений, межгородских дорог и внешнего въезда. Здесь же находятся список городов и параметры новой карты. «Город» — основной режим с карточкой ратуши и нижней панелью местного строительства. Основание или открытие поселения переводит камеру в город; переключение режима отменяет незавершённый инструмент.
- «Основать поселение» размещает ратушу с площадью и резервом земли для будущего расширения. Перед фасадом автоматически строится стартовая дорога; её стоимость видна в предпросмотре. Активный город выбирается в его панели; новые зоны и склады принадлежат ему.
- Круг вокруг ратуши ограничивает местные дороги, склады и целые участки застройки. Межгородские дороги в режиме региона можно строить за этим кругом. В «Развитии ратуши» игрок вручную улучшает её за общий бюджет, когда построено достаточно готовых зданий с действующим подъездом; радиус и корпуса увеличиваются вместе с уровнем. Текущие размеры, цены и требования заданы в `packages/app/src/region/model/rules.ts`. Пустая разметка не открывает улучшение. Существующая застройка из старых сохранений за новым радиусом остаётся на месте.
- «Дорога» задаёт точки прямого или ломаного маршрута произвольного направления; `Enter` подтверждает. Пересечения соединяют дорожную сеть. Доступны двухполосные дороги без мостов и тоннелей.
- «Жилая зона», «Торговая зона», «Производственная зона» размечают низкоплотные участки у дороги. «Склад» размещает особый объект вручную; его положение и поворот привязаны к подъезду.
- «Внешний въезд» назначает дорожный конец на границе региона. «Выбор» показывает объект, «Снос» удаляет выбранный объект. Занятая дорога сначала закрывается для новых поездок и исчезает после проезда текущего транспорта. Занятые дома, предприятия и объекты с грузом не сносятся. Участки после удаления дороги сохраняются и показывают отсутствие доступа. Ратуша и её стартовая дорога удаляются вместе при выборе любой из них; при наличии принадлежащих поселению участков или складов снос центра блокируется.
- Левое перетаскивание в «Выборе» перемещает камеру; в строительных инструментах для перемещения держите `Space`. Правая кнопка вращает, колесо меняет масштаб. `WASD` перемещает камеру относительно ракурса, `Q/E` поворачивают её; используются физические клавиши и в русской раскладке. При вводе названия или работе с диалогом клавиши остаются у поля. `Escape` отменяет предпросмотр и возвращает выбор. Панель показывает стоимость и причину отказа; неподтверждённый предпросмотр не списывает бюджет.
- «Сохранить» записывает планировку и весь живой мир в отдельное хранилище IndexedDB. «Загрузить» есть в регионе и главном меню; одинаковый seed не объединяет разные регионы. В обоих списках можно удалить выбранное сохранение после подтверждения. Удаление записи не сбрасывает текущий мир: его можно продолжить и сохранить снова. Формат v3 сохраняет стройки, частные счета, семьи, рабочие места, фактические парковки, движение, заказы и груз в пути. Регионы v1/v2 получают пустую симуляцию с сохранением земли, ID и бюджета; старые v3 без истории семейных расходов начинают её при первом новом платеже. Сохранения прототипа города остаются отдельными. Сквозная река добавляется при создании нового региона.

Новая карта и загрузка начинаются на паузе. Чтобы запустить развитие, подведите дорогу к краю карты, обозначьте внешний въезд, разметьте жильё, торговлю и производство, затем нажмите ▶. Скорости ×1/×5/×20/×120 меняют общие часы; переход между городами не останавливает дальний город. При скрытии вкладки симуляция ставится на паузу. «День»/«Ночь» меняют освещение независимо от часов.

Подключённый въезд открывает конечный список семей и инвесторов. Дома и предприятия оплачиваются их капиталом и сначала строятся. Семья приезжает по дороге к готовому жилью с доступной работой; работа может находиться в другом городе. Один семейный автомобиль имеет конкретного водителя и парковку, остальные поездки могут быть пешими. «Жители города» открывает список; выбор человека, машины или здания показывает реальные сведения, маршрут, ожидание, запасы и семейные расходы.

Предприятие производит один вид товара при наличии работников. Магазины и склады заказывают реальные поставки у местных производителей или через внешний въезд. Погрузка снимает товар у отправителя, разгрузка добавляет его получателю; магазины не пополняются по таймеру. Покупки, зарплаты, налог с выручки, импорт и содержание имеют явные счета. Параметры этого первого экономического цикла находятся в `packages/app/src/region/model/life/rules.ts`.

Свободное размещение портов и вокзалов, общественный транспорт, школы и медицина, мосты, рельеф и расширение ассортимента остаются следующими самостоятельными системами. Существующий порт и железная дорога продолжают работать в отдельном прототипе ниже.

Карта расширена с 7×7 до 9×9 кварталов на север и запад. Исходные здания и порт сохранили свои координаты и наборы деталей; новые жилые и торговые улицы подключены к общей сети. Для ключа `689856` это 248 зданий, в том числе 64 одноэтажных дома с участками. Железнодорожный коридор проходит между новыми северными кварталами и прежним городом.

Жизнь города моделируется в собственном Web Worker (`src/city/life/`). Начальный город заселён 540 жителями в 180 семьях. У каждого есть постоянный ID, дом, родство, образование, работа и распорядок. Зарплата, продукты, жильё и автомобиль меняют семейный бюджет. Новые семьи приезжают поездом или на микроавтобусе; дети рождаются, взрослеют и начинают работать. Модель прежнего движка автоматически не подключается.

Пассажирские составы идут по двум путям в противоположных направлениях, останавливаются у платформ, открывают двери и отправляются. Приезжие выходят по очереди и идут к своему жилью; северную платформу с городом связывает надземный переход. На десяти переездах мигают сигналы и опускаются шлагбаумы. Машины и пешеходы ждут, а поезд пропускает уже вошедших на переезд. Интервал между отправлениями составов на линию — 220 с общего времени симуляции, остановка у вокзала — 18 с. Это междугородное прибытие новых семей; поездки существующих жителей на поездах пока не моделируются.

Личный автомобиль принадлежит семье и остаётся на последней парковке. Житель сравнивает пеший путь со временем подхода к машине, поездки и пути от парковки до двери. Он не может воспользоваться машиной, которую забрал другой член семьи. Места на участках доступны хозяевам; подземные паркинги имеют конечную вместимость; уличные места вдоль бордюра открыты всем. Их геометрия привязана к участкам улиц: парковочная полоса шириной 2,1 м, пары мест с разметкой и непрерывный тротуар. Внутри города такие места занимают часть широкого тротуара у парков; въезды к зданиям и переходы свободны. Водители ищут другое место, если выбранное занято. Переходы связывают тротуары; пешеходы проверяют приближающиеся машины, транспорт пропускает уже идущих людей.

Симуляция движется шагами по 0,05 с. На ×1 одна игровая минута занимает 3 с, сутки — 72 мин; ×5 и ×20 ускоряют общее время. Порт и семейные машины используют общую дорожную модель. Внутренние этажи парковок не рисуются: автомобиль скрывается за въездом и сохраняется в конкретном внутреннем месте.

Экономика пока базовая: один автомобиль на семью, покупка занимаемого жилья или аренда, работа по квалификации и расстоянию, продукты и досуг. Рынок перепродажи, ипотека, образование по ступеням и общественный транспорт внутри города остаются дальнейшими этапами.

## Управление прототипом города

- Прототип открывается вторичной ссылкой меню; `Enter` в меню открывает основной редактор региона.
- Перетаскивание левой кнопкой перемещает камеру по карте; правой кнопкой — вращает её; колесо меняет масштаб. На тачпаде для вращения используйте правое нажатие двумя пальцами с перетаскиванием. Короткий левый клик выбирает жителя, его машину или здание.
- При фокусе на городе стрелки вращают камеру, `+` и `−` меняют масштаб, `Escape` сбрасывает вид и выбор.
- «Жители» открывает список и карточку семьи: дом, работа, бюджет, автомобиль и журнал событий. «Следовать за жителем» включает ракурс сверху, чтобы высотки не закрывали человека или его машину; ручное перетаскивание отключает слежение.
- «P Парковки» показывает свободные, занятые и резервируемые места; нажатие на место или въезд раскрывает доступ и стоимость.
- «ЖД вокзал» переносит камеру к платформам и показывает прибытия, отправления, новых жителей и состояние переездов. Короткий клик по зданию вокзала открывает эту же панель.
- «Сохранить» и «Загрузить» в панели жителей сохраняют весь мир для текущего ключа в IndexedDB этого устройства, включая активные поездки, порт, поезд и шлагбаумы. Совместимые сохранения прежней карты 7×7 переводятся в расширенный город с сохранением времени, жителей и имущества. Загрузка ставит игру на паузу. Перезагрузка страницы сама по себе начинает новый день: для продолжения нажмите «Загрузить».
- «Пауза» останавливает симуляцию, порт, поезда и строительство; «День» и «Ночь» меняют освещение.
- Нажатие на дом показывает его состав; «Показать строительство» запускает стройку выбранного здания.
- «Строить» открывает просмотр строительства с примерами дома, башни и промышленного корпуса. Ползунок позволяет рассмотреть любой этап; кран, ограждение и материалы исчезают после завершения.

## Кодстайл и строгие проверки

Контракт разработки — [`CODESTYLE.md`](CODESTYLE.md), основа — Google TypeScript Style Guide. Форматирование Google/gts задают `.editorconfig` и `.prettierrc.json`; Prettier закреплён точной версией. TypeScript проверяет приложение, worker без DOM, Electron, сборочные скрипты и тесты. ESLint использует сведения о типах, проверяет обработку Promise, полноту `switch` и границы чистой симуляции. ESLint Stylistic требует пустые строки между группами кода; смысловые границы внутри функций определяет автор. Активный код приведён к общему стилю; архив, исторические документы и локальные артефакты сессий не переформатируются.

```bash
bun run format        # применить форматирование
bun run format:check  # проверить без изменений
bun run lint:fix      # автоматические исправления ESLint
bun run check         # форматирование, типы, lint, unit-тесты и неделя симуляции
```

Недельный прогон можно запустить отдельно: `bun run test:life-week`. Он проверяет будние поездки, выходные и отсутствие зависших маршрутов. CI запускает эти проверки, сборку и e2e. Изменения GitHub branch protection не выполняются этой конфигурацией.

`bun run test:region-week` проверяет две свободно построенные планировки на одном seed за неделю: межгородскую работу, закрытие и восстановление дороги, точное продолжение сохранения, сохранение денег и товаров и отсутствие зависших поездок. Нагрузочный вариант: `bun run test:region-week -- --performance --output=.scratch/region-playthrough/performance.json`; он использует отдельный явный бюджет 3 млн для большого числа вручную построенных складов и сохраняет результат только после достижения 1000 жителей и 200 готовых зданий. Проверка кадров: `REGION_PERF_SAVE="$PWD/.scratch/region-playthrough/performance.json" E2E_GPU=1 bun run e2e e2e/region-life-performance.spec.ts --workers=1`.

## Проверки и сборка

```bash
bun run typecheck
bun run lint
bun run test        # Vitest; не bun test
bun run e2e         # Chromium, headless
bunx vite build packages/app
```

Vite собирает единое приложение на корне, совместимый редирект `/region/` и прототип города, включая отдельные worker bundles. Подразделы разрешены для проверок и прототипов; основная игра и её меню остаются на `/`. Архив не входит в клиентскую сборку или обычные проверки. Его отдельные команды приведены в [`deprecated/README.md`](deprecated/README.md).

Для e2e можно задать `E2E_PORT`; `E2E_GPU=1` включает ANGLE Metal для локальных проверок на GPU.

```bash
bun run desktop:dev
bun run desktop:build
bun run desktop:build:test
SIMCITY_TEST_WINDOW=1 bun run desktop:e2e
```

Собранное приложение: `packages/desktop/release/mac-arm64/SimCity.app`. Для проверок Electron нужны обычная и тестовая сборки одного коммита; проверки идут без видимого окна. В релизе сохранены ограничения отладки и защитные настройки Electron. Устаревший `window.__sim` не входит ни в одну сборку текущей игры.
