# SimCity

Градостроительная игра для десктопа на TypeScript + Three.js. Целевая оболочка — Electron; Chromium используется для разработки и проверок. Мобильная версия не входит в проект. Игра расширена до **региона**: непрерывная карта 4 × 4 км, где игрок основывает города, строит дороги и размещает целые исходные кварталы, а семьи и предприятия заселяют застройку, ездят на работу и перевозят товары. **«Город у воды»** является основой основной игры: корень запускает его исходный движок, составные здания, жителей, транспорт, работающий порт, вокзал и строительство. Эталонный вход `/city/` использует этот же runtime.

Исходный город — основа игры и закреплённый эталон: полные здания, участки, сады, гаражи, транспорт, корабли и порт сохраняют свои размеры и детали. Регион добавляет карту, размещение объектов и реальные поставки вокруг того же движка. Прежняя игра имеет статус **deprecated** и сохранена в [`deprecated/`](deprecated/README.md).

## Запуск

```bash
bun install
bun run dev        # http://localhost:5174
```

Новая игра создаёт пустой регион. Обычные сохранения исходного города и авторского региона открываются из общего каталога. «Импортировать файл» добавляет обычный JSON-сейв без отдельного деморежима. Старые региональные записи сохраняются: разрешённый тестовый мир можно импортировать в новую отдельную запись; ручные миры требуют адаптации участков и не перестраиваются автоматически. Неподдерживаемые активные операции старого формата сообщают причину отказа и оставляют оригинал целым.

Вся основная игра работает на `/` в одном приложении. Главное меню, создание региона, загрузка и управление городом переключаются без перезагрузки страницы. «Создать регион» начинает новую карту; `Enter` делает то же. «Загрузить» раскрывает список сохранённых регионов с названиями поселений и ключом карты; выбор записи продолжает именно этот мир. Повреждённые записи остаются в списке недоступными для загрузки. Кнопка «Удалить» удаляет выбранное сохранение после подтверждения; ошибка хранилища оставляет запись в списке. `Escape` закрывает список. Возврат в главное меню ставит игру на паузу, а «Продолжить» возвращает тот же мир и камеру из памяти. Небольшая ссылка «Город у воды — прототип» открывает `/city/?seed=689856`. Прежние игровые сценарии удалены из обычного запуска; первый прототип «Тихий квартал» удалён.

- `/city/?seed=<ключ>` — воспроизводимый город по ключу.
- `&view=harbor` — камера у работающего порта.
- `&view=construction` — просмотр строительства.
- `&view=houses` — одноэтажные дома с частными участками, садами и разными ограждениями.
- `&view=railway` — пассажирский вокзал, поезда и железнодорожные переезды.
- Логотип SimCity в городе возвращает в главное меню.

## Региональная игра

- `/?seed=<ключ>` создаёт пустую карту 4 × 4 км с озёрами, сквозной рекой и растительностью. `/?seed=<ключ>&regionId=<ID>` продолжает сохранённый мир; `/region/` перенаправляет на корень. Один `CityLife`, `Population`, `ParkingBook` и `CityTraffic` обслуживают все города.
- В режиме «Регион» игрок основывает поселения, соединяет их дорогами, назначает внешний въезд, размещает порт и вокзал. В режиме «Город» доступны исходные частные дома, жилые, торговые, производственные и деловые кварталы, школа и парк. Кварталы используют полные сборки прототипа в масштабе 1:1; участки подстраиваются под них.
- Ратуша появляется с площадью, резервом роста и стартовой дорогой. Её радиус ограничивает местное строительство. Улучшение ручное: нужны готовые кварталы и средства; уровни заданы в `region/model/rules.ts`. Ратуша и стартовая дорога удаляются вместе; застроенный город или занятый объект сносить нельзя.
- Для дороги выберите начало и конец; пересечения и близкие концы соединяют сеть. Региональные дороги не ограничены радиусом города. Внешний въезд назначается концу дороги на границе карты. Жителям необходим действительный путь прибытия и возвращения: тупик не создаёт невидимый разворот.
- Новые здания сначала проходят исходную стройку с краном и ограждением; жильё, рабочие места и парковки регистрируются после готовности. Изменение документа сохраняет существующих жителей, имущество, движение и парковку в том же worker. Удаление занятой дороги отклоняется до завершения текущих поездок.
- Порт размещается на берегу с проходимым маршрутом для полного корпуса корабля до края региона; он включает исходные склады, краны и грузовики. Вокзал сохраняет исходный поезд, платформы, мост и переезды. Школа и парк подключены к исходным процедурам жителей.
- Фабрики производят товары трудом реальных работников. Магазины и склады получают оплаченные физические поставки. Порт использует те же запасы и счета; груз имеет одного владельца на каждом этапе. Семейные покупки, аренда, собственность, зарплаты и налоги используют исходные счета; магазины в авторском регионе не пополняются по таймеру. Правила авторского поставщика находятся в `city/life/goodsEconomy.ts`; исходные цены и зарплаты прототипа сохранены.
- Левая кнопка перемещает камеру в режиме выбора; при строительстве держите `Shift`. Правая кнопка вращает, колесо меняет масштаб. `WASD` перемещают камеру, `Q/E` поворачивают; поля ввода и диалоги сохраняют клавиатуру. `Escape` отменяет инструмент. «Весь регион» открывает общий обзор; кнопки городов возвращают к ратушам. Поворот размещаемого объекта — 90°.
- «Жители» открывает исходную карточку семьи, работы, автомобиля и событий; «P Парковки» показывает реальные места. Там же находятся сохранение и загрузка. Главное меню содержит каталог, импорт JSON и удаление выбранной записи с подтверждением. Удаление записи не сбрасывает продолжаемый мир.

Новая карта и загрузка начинаются на паузе. Подключите дорогу к краю региона, обозначьте внешний въезд, постройте готовое жильё и рабочие места, затем включите движение. Скорости ×1/×5/×20 ускоряют общий native clock; скрытое меню останавливает весь мир. «День»/«Ночь» меняют освещение. Сохранение содержит документ карты, устойчивые ID, физические часы, семьи, имущество, реальные запасы, движение, парковку, стройки, порт и поезд. Старые часы сохраняются при поддерживаемом импорте.

Мосты, тоннели, медицина и расширенный ассортимент остаются будущими системами. Исторические проверки заменённого регионального движка хранятся отдельно и не подтверждают работу текущей игры.

| `packages/app/index.html`, `src/main.ts` | Одна игра и внутреннее меню на `/`                                                    |

## Управление прототипом города

- Прототип открывается вторичной ссылкой меню; `Enter` в меню открывает основной редактор региона.
- Перетаскивание левой кнопкой перемещает камеру по карте; правой кнопкой — вращает её; колесо меняет масштаб. На тачпаде для вращения используйте правое нажатие двумя пальцами с перетаскиванием. Короткий левый клик выбирает жителя, его машину или здание.
- При фокусе на городе стрелки вращают камеру, `+` и `−` меняют масштаб, `Escape` сбрасывает вид и выбор.
- «Жители» открывает список и карточку семьи: дом, работа, бюджет, автомобиль и журнал событий. «Следовать за жителем» включает ракурс сверху, чтобы высотки не закрывали человека или его машину; ручное перетаскивание отключает слежение.
- «P Парковки» показывает свободные, занятые и резервируемые места; нажатие на место или въезд раскрывает доступ и стоимость.
- «ЖД вокзал» переносит камеру к платформам и показывает прибытия, отправления, новых жителей и состояние переездов. Короткий клик по зданию вокзала открывает эту же панель.
- «Сохранить» и «Загрузить» в панели жителей сохраняют весь мир для текущего ключа в IndexedDB этого устройства, включая активные поездки, порт, поезд и шлагбаумы. Совместимые сохранения прежней карты 7×7 переводятся в расширенный город с сохранением времени, жителей и имущества. Загрузка ставит игру на паузу. Перезагрузка страницы сама по себе начинает новый день: для продолжения нажмите «Загрузить».
- «Пауза» останавливает симуляцию, порт, поезда и строительство; «День» и «Ночь» меняют освещение.
- Нажатие на дом показывает его состав; «Показать строительство» запускает стройку выбранного здания.
- «Строить» открывает просмотр строительства с примерами дома, башни и промышленного корпуса. Ползунок позволяет рассмотреть любой этап; кран, ограждение и материалы исчезают после завершения.

## Кодстайл и строгие проверки

Контракт разработки — [`CODESTYLE.md`](CODESTYLE.md), основа — Google TypeScript Style Guide. Форматирование Google/gts задают `.editorconfig` и `.prettierrc.json`; Prettier закреплён точной версией. TypeScript проверяет приложение, worker без DOM, Electron, сборочные скрипты и тесты. ESLint использует сведения о типах, проверяет обработку Promise, полноту `switch` и границы чистой симуляции. ESLint Stylistic требует пустые строки между группами кода; смысловые границы внутри функций определяет автор. Активный код приведён к общему стилю; архив, исторические документы и локальные артефакты сессий не переформатируются.

```bash
bun run format        # применить форматирование
bun run format:check  # проверить без изменений
bun run lint:fix      # автоматические исправления ESLint
bun run check         # форматирование, типы, lint, unit-тесты и неделя симуляции
```

Недельный прогон можно запустить отдельно: `bun run test:life-week`. Он проверяет будние поездки, выходные и отсутствие зависших маршрутов. CI запускает эти проверки, сборку и e2e. Изменения GitHub branch protection не выполняются этой конфигурацией.

Нагрузочный native прогон: `bun tools/test-native-region-week.ts /absolute/path/save.json --days=7 --report=/absolute/path/report.json --checkpoint=/absolute/path/checkpoint.json`; он продолжает обычный сейв с исходным календарём и проверяет деньги, товары, ID, парковку и реальные поездки. Проверка кадров: `NATIVE_REGION_PERFORMANCE_SAVE="/absolute/path/active-save.json" E2E_GPU=1 bun run e2e e2e/native-region-performance.spec.ts --workers=1`. Требуется естественно достигнутый checkpoint с ≥1000 жителей, ≥200 готовых зданий и активным движением. Архивная диагностика `test:legacy-region-week` проверяет только прежний региональный движок.

## Проверки и сборка

```bash
bun run typecheck
bun run lint
bun run test        # Vitest; не bun test
bun run e2e         # Chromium, headless
bunx vite build packages/app
```

Vite собирает единое приложение на корне, совместимый редирект `/region/` и прототип города, включая отдельные worker bundles. Подразделы разрешены для проверок и прототипов; основная игра и её меню остаются на `/`. Архив не входит в клиентскую сборку или обычные проверки. Его отдельные команды приведены в [`deprecated/README.md`](deprecated/README.md).

Для e2e можно задать `E2E_PORT`; `E2E_GPU=1` включает ANGLE Metal для локальных проверок на GPU.

```bash
bun run desktop:dev
bun run desktop:build
bun run desktop:build:test
SIMCITY_TEST_WINDOW=1 bun run desktop:e2e
```

Собранное приложение: `packages/desktop/release/mac-arm64/SimCity.app`. Для проверок Electron нужны обычная и тестовая сборки одного коммита; проверки идут без видимого окна. В релизе сохранены ограничения отладки и защитные настройки Electron. Устаревший `window.__sim` не входит ни в одну сборку текущей игры.
