# SimCity

Градостроительная игра на TypeScript + Three.js. С 2026-10-02 основой разработки стал **«Город у воды»** — текущий процедурный город с составными зданиями, машинами, людьми, работающим портом и анимацией строительства.

Графика этого города — ориентир для дальнейшего развития, включая транспорт, жителей, корабли и порт. Механики переносим из прежней игры по отдельности либо реализуем заново здесь. Прежняя игра имеет статус **deprecated** и сохранена в [`deprecated/`](deprecated/README.md).

## Запуск

```bash
bun install
bun run dev        # http://localhost:5174
```

В главном меню один пункт — «Город у воды». Он открывает `/city/?seed=689856`. Другие игровые сценарии удалены из обычного запуска; первый прототип «Тихий квартал» удалён.

- `/city/?seed=<ключ>` — воспроизводимый город по ключу.
- `&view=harbor` — камера у работающего порта.
- `&view=construction` — просмотр строительства.
- `&view=houses` — одноэтажные дома с частными участками, садами и разными ограждениями.
- Логотип SimCity в городе возвращает в главное меню.

## Текущий код

| Путь | Назначение |
|---|---|
| `packages/app/index.html`, `packages/app/src/main.ts` | Главное меню |
| `packages/app/city/index.html`, `packages/app/src/city/` | Игра: город, графика, транспорт, порт и строительство |
| `packages/app/src/city/primitives.ts`, `base.css` | Общие детали графики и оформления, перенесённые из первого прототипа |
| `packages/desktop/` | Electron-оболочка текущей игры |
| `packages/app/test/`, `e2e/` | Проверки текущего города и меню |
| `deprecated/` | Прежняя симуляция, рендер, HUD, города и их проверки — материал для переиспользования |

В текущем городе пока своя визуальная модель жизни. Экономика и остальные системы старого движка автоматически не подключены. Его воркер не запускается при открытии меню или города.

## Управление

- В меню `Enter` открывает город.
- Перетаскивание левой кнопкой перемещает камеру по карте; правой кнопкой — вращает её; колесо меняет масштаб. На тачпаде для вращения используйте правое нажатие двумя пальцами с перетаскиванием. Короткий левый клик выбирает здание.
- При фокусе на городе стрелки вращают камеру, `+` и `−` меняют масштаб, `Escape` сбрасывает вид и выбор.
- «Пауза» останавливает движение и строительство; «День» и «Ночь» меняют освещение.
- Нажатие на дом показывает его состав; «Показать строительство» запускает стройку выбранного здания.
- «Строить» открывает просмотр строительства с примерами дома, башни и промышленного корпуса. Ползунок позволяет рассмотреть любой этап; кран, ограждение и материалы исчезают после завершения.

## Проверки и сборка

```bash
bun run typecheck
bun run lint
bun run test        # Vitest; не bun test
bun run e2e         # Chromium, headless
bunx vite build packages/app
```

Vite собирает обе страницы: главное меню и город. Архив не входит в клиентскую сборку или обычные проверки. Его отдельные команды приведены в [`deprecated/README.md`](deprecated/README.md).

Для e2e можно задать `E2E_PORT`; `E2E_GPU=1` включает ANGLE Metal для локальных проверок на GPU.

```bash
bun run desktop:dev
bun run desktop:build
bun run desktop:build:test
SIMCITY_TEST_WINDOW=1 bun run desktop:e2e
```

Собранное приложение: `packages/desktop/release/mac-arm64/SimCity.app`. Для проверок Electron нужны обычная и тестовая сборки одного коммита; проверки идут без видимого окна. В релизе сохранены ограничения отладки и защитные настройки Electron. Устаревший `window.__sim` не входит ни в одну сборку текущей игры.
